## 在做的事

**NTFS 读写助手** — macOS 菜单栏常驻工具，让系统对 NTFS 磁盘从只读变成原生读写。

底层走 FUSE-T + ntfs-3g 用户态方案，不依赖 Apple 签名的 FSKit 扩展，也就不需要付费开发者账号。
插盘自动挂载、拔盘自动清理，用户主动推出后不会擅自挂回。

`Swift` · `FUSE` · `macOS`

**杨杨的博客** — 自己写的 PHP 博客系统，文章以 Markdown 存库、服务端渲染，不依赖任何框架，跑在一台自己的 VPS 上。

**怀旧游戏站** — 浏览器里跑的复古游戏平台，模拟器内核自托管，存档走服务端。

## 我关心的

- 用户态方案优先：能用 FUSE / 用户态解决的，不去碰系统扩展和签名授权
- 小工具就该小：单文件、零依赖、拖进「应用程序」就能用
- 状态要能收敛：宁可每 3 秒对账一次，也不相信会丢的事件通知
